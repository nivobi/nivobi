# Hi, I'm Nicolai 👋

Also known online as **Nivobi**. I'm a developer in Aarhus, Denmark, and I like building things end to end: the idea, the code, the server it runs on, and the update that reaches the people using it. I learn by building: most of these projects started because I wanted to understand how something works. I'm curious about most corners of tech, from web and AI to servers, hardware, IoT and security, and there's always something new I'm learning.

## 🛠️ Things I've built

- **[NivoTask](https://github.com/nivobi/NivoTask)**: Kanban board with time tracking. Ships as one process with a setup wizard, migrations that run themselves, and self-updates on Windows, Linux and macOS.<br>`.NET 10` `Blazor WASM` `EF Core` `MySQL`

- **[Trustpilot Reviews for WordPress](https://github.com/nivobi/trustpilot-plugin-releases)**: OAuth2 sync that never wipes existing reviews when a run fails, per-product carousels, self-updating via GitHub Releases.<br>`PHP` `WordPress` `React` `MySQL`

- **Prism**: a Lightroom-style raw photo editor, because I didn't want to pay for Adobe. Built by AI agents from a GitHub project board: 1,100+ commits, tests before code, mutation-verified tests.<br>`Qt6` `SQLite` `Metal/Vulkan`

- **[Swipe2Job](https://nivobi.com/projects/swipe2job)**: Tinder, but for job ads. Ranks ~4,000 listings with local embeddings, and two models compete on predicting my latest swipes.<br>`React` `FastAPI` `Ollama` `Docker`

- **[FootyBot](https://nivobi.com/projects/footybot)**: Discord bot with live football scores as image cards and a World Cup prediction game (16 players, 579 predictions, 36 exact scores called).<br>`TypeScript` `discord.js` `Canvas`

- **[Internet Stability Monitor](https://nivobi.com/projects/internet-stability-monitor)**: logged 4.1 million modem readings over a month to prove a line fault to my ISP.<br>`Python` `Flask` `SQLite` `Docker`

More projects and dev logs on **[nivobi.com](https://nivobi.com)**.

## 🏠 Homelab

An old gaming PC turned Ubuntu server: **Ryzen 7 1700X, 32 GB RAM, RTX 2070 Super, 128 GB SSD + 1 TB HDD**. Everything I run lives there in Docker: bots, dashboards, local AI models on the GPU, Pi-hole and Jellyfin, reachable through Cloudflare Tunnels and Tailscale. The story: [From Gaming Rig to Dev Rig](https://nivobi.com/blog/homelab).
